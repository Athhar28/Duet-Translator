# Duet Translator

Two free voice-translation apps that run in the phone's browser and install like normal apps.

## Duet — face-to-face translator
**https://athhar28.github.io/Duet-Translator/**

- You and the other person each speak your own language. Each of you sees and hears the
  translation in yours.
- **Hands-free:** tap the mic once and keep talking. **Take turns** passes the mic back and forth.
- **Face-to-face** mode turns the top half around for the person sitting opposite.
- Settings let you choose the pause length, voices and speaking speed.

## Khutbah Translator
**https://athhar28.github.io/Duet-Translator/khutbah.html**

- Listens to the imam's Arabic khutbah and speaks a live **Urdu** or **Hindi** translation
  into your earphones, sentence by sentence.
- Shows a large scrolling transcript, has a dim-screen mode, and saves the full khutbah as a text file.

## Install on Android
1. Open the link in **Google Chrome**.
2. Tap ⋮ → **Add to Home screen** (or **Install app**).
3. Allow the microphone the first time.

A step-by-step picture guide is in [`docs/`](docs/).

## Chrome extension (desktop)
The [`extension/`](extension/) folder has a side-panel version of Duet that can also translate
live captions in Google Meet, Teams and Zoom. To install it, open `chrome://extensions`, turn on
Developer mode, click **Load unpacked** and select the `extension` folder.

## Limits
- Needs internet. Speech recognition and translation are online services.
- Translation is automatic and not as accurate as a human translator, especially for Qur'anic verses.
- Use earphones so the phone doesn't hear its own voice.
